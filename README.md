# NETFLIX-Dashboard
NETFLIX Dashboard
This project presents an interactive Netflix Analysis Dashboard built using Power BI. The dashboard provides insights into Netflix's content library, including movies, TV shows, genres, ratings, release trends, directors, and geographical distribution.

The goal of this dashboard is to help users understand Netflix's content portfolio through visually appealing and data-driven analytics.

The Dashboard was built using the following tools and technologies:
📊 Power BI Desktop
🗂️ Netflix Dataset
🧹 Data Cleaning & Transformation
⚙️ Power Query
🧮 DAX Measures
📈 Data Visualization

Source: kaggle

Features or Highlights:
🎬 Netflix library contains 5,189 Movies and 147 TV Shows
🌍 Content is distributed across multiple countries worldwide
⭐ TV-MA and TV-14 are the most common content ratings
🎭 International and Crime genres are among the most popular TV show categories
📈 Significant growth in content releases observed after 2010
🍿 Movies dominate the platform, accounting for over 97% of the content
📊 Provides quick insights into Netflix's content strategy and global reach
